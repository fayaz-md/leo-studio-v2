# Leo Studio V2

Leo Studio V2 is an AI Animation Production Platform.

It generates complete animated stories from a single idea.

Current Features

- Story Generation
- Character Manager
- Voice Manager
- Scene Voice Generation

Planned Features

- Character Memory
- Emotion Engine
- Image Generator
- Timeline Engine
- Video Builder
- Subtitle Engine
- AI Director

Current Version: 2.0.0
