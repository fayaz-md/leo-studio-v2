# 🌍 Leo Universe

Version: 1.0

---

# Purpose

This document defines the creative universe of Leo Studio.

Unlike the software architecture, this document describes the fictional world, its rules, characters, locations, and long-term continuity.

Every story generated by Leo Studio belongs to a universe.

---

# Universe Philosophy

Leo Studio creates connected worlds instead of isolated stories.

Characters can return.

Locations can return.

Relationships can grow.

Knowledge can expand.

The universe should feel alive and consistent.

# Series

A universe may contain multiple series.

Examples:

- Leo Adventures
- Leo Science Lab
- Leo Animal World
- Leo History Time
- Leo Space Explorer

Each series may have its own:

- Main Character
- Supporting Characters
- Story Template
- Genre
- Educational Goal

---

# Main Character

The main character is configurable.

Examples:

Leo Adventures

Main Character:

Leo

Leo Science Lab

Main Character:

Professor Ananya

Nova Space Explorer

Main Character:

Robot Nova

Changing the main character must never require architectural changes.

---

# Universal Character System

Every recurring character belongs to the universe.

Supported character types:

- Human
- Animal
- Robot
- Alien
- Dinosaur
- Historical Figure
- Mythical Character
- Fantasy Character
- Custom Character

All characters follow the same lifecycle.

---

# Character Rules

Every recurring character must have:

- Permanent ID
- Display Name
- Character Type
- Appearance
- Voice
- Personality
- Relationships
- Episode History

Characters may evolve through experiences, but their core identity must remain consistent.

---

# World Rules

Locations belong to the universe.

Examples:

- Forest
- River
- Village
- School
- Laboratory
- Space Station

Recurring locations should remain visually recognizable across episodes.

---

# Object Rules

Reusable props include:

- Balloons
- Baskets
- Rockets
- Books
- Treasure Chests
- Vehicles
- Scientific Equipment

Props may appear across multiple series.

---

# Educational Rules

Educational content should be:

- Accurate
- Age appropriate
- Engaging
- Easy to understand

Future versions will use the Knowledge Engine for verified facts.

---

# Continuity Rules

Leo Studio should remember:

- Characters
- Locations
- Relationships
- Recurring objects
- Previous appearances

Future episodes should feel like they belong to the same universe.

---

# Creative Freedom

The universe supports:

- Adventure
- Comedy
- Science
- History
- Geography
- Animal Stories
- Fantasy
- Mystery
- Space Exploration

New series should extend the universe rather than replace it.

---

# Long-Term Goal

Build a reusable animated universe capable of supporting multiple long-running series while maintaining consistent characters, locations, and storytelling quality.
