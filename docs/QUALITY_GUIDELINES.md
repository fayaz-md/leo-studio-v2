# 🎬 Leo Studio Quality Guidelines

Version: 1.0

---

# Purpose

This document defines the production quality standards for every episode generated by Leo Studio.

Every new feature should improve one or more of these quality areas.

---

# Story Quality

Every episode must:

- Capture attention within the first 3 seconds.
- Present a clear problem.
- Build curiosity.
- Reach a satisfying climax.
- End positively.
- Include a moral or educational takeaway when appropriate.

---

## Opening Hook

Avoid slow introductions such as:

> One day...

Instead start with:

- A question
- A surprise
- A mystery
- A danger
- A funny moment

The viewer should immediately want to continue watching.

---

## Story Structure

Preferred structure:

Hook

↓

Problem

↓

Adventure

↓

Climax

↓

Resolution

↓

Signature Ending

---

## Episode Length

Target runtime:

45–60 seconds

Scene duration should never be hardcoded.

Video timing must always be derived from generated audio.

---

# Character Quality

Characters are the most valuable assets of Leo Studio.

Every recurring character must maintain:

- Same appearance
- Same voice
- Same personality
- Same catchphrases
- Same identity

Across all scenes and all future episodes.

---

## Universal Character System

Supported character types:

- Human
- Animal
- Robot
- Alien
- Dinosaur
- Historical Figure
- Mythical Character
- Fantasy Character
- Custom Character

All character types use the same profile structure.

---

## Character Locking

When a recurring character appears for the first time:

Leo Studio should:

- Create a character profile.
- Assign an appearance.
- Assign a permanent voice.
- Assign a personality.
- Lock the profile.

Future episodes must reuse the same character.

---

# World Quality

Locations should remain visually consistent.

Reusable examples:

- Forest
- River
- School
- Village
- Laboratory
- Space Station

Props should also be reusable.

---

# Image Quality

Every image should:

- Be visually consistent.
- Show expressive emotions.
- Match the story.
- Include cinematic composition.
- Maintain character consistency.
- Include one thumbnail-quality scene.

---

# Audio Quality

Every character owns a permanent voice.

Future improvements:

- Emotion-aware speech
- Background music
- Ambient sounds
- Sound effects

Narration should support the story rather than dominate it.

---

# Video Quality

Every episode should include:

- Smooth transitions
- Camera movement
- Professional pacing

Future improvements:

- Ken Burns effect
- Subtitle burn-in
- Visual effects

---

# Educational Quality

Educational episodes must:

- Use verified facts.
- Explain concepts appropriate for children.
- Focus on one primary learning objective.
- Distinguish facts from fictional storytelling.

---

# Automation Quality

Leo Studio should automate repetitive work while allowing human review when needed.

Examples:

- Character creation
- Voice assignment
- Timeline generation
- Prompt generation
- Video rendering

---

# Publishing Quality

Every episode should include:

- Attractive title
- Thumbnail
- Description
- Tags
- Series branding
- Signature ending

---

# Definition of Done

An episode is considered complete only when:

- Story quality standards are met.
- Character consistency is maintained.
- Voice consistency is maintained.
- Visual quality is maintained.
- Audio is synchronized.
- Video renders successfully.
- Final review is completed.
